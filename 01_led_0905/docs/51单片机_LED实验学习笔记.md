## 1. 什么是单片机

可以先把单片机理解成：

**一个很小、可以按照程序运行，并控制外部硬件的计算机。**

它里面主要有：

- **处理器**：执行程序，可以理解成“大脑”
- **存储器**：存程序和数据
- **I/O 接口**：和 LED、蜂鸣器、按键等外部电路连接

最基本的工作过程：

```text
我们写程序
    ↓
单片机执行程序
    ↓
引脚输出电信号
    ↓
控制 LED / 蜂鸣器 / 继电器
```

---

## 2. 什么是 I/O 口

I/O：

- I = Input，输入
- O = Output，输出

PPT 中的：

- P0
- P1
- P2
- P3
- P4

都属于 I/O 口。

例如：

- `P2.5`：P2 这一组中的第 5 位引脚
- `P2.6`：P2 这一组中的第 6 位引脚
- `P2.7`：P2 这一组中的第 7 位引脚

这些都是单片机上的具体物理引脚，可以通过程序让它们输出 0 或 1。

---

## 3. VCC、GND、XTAL、RST

### VCC

电源正端，用来给单片机供电。

### GND

地，可以先理解成 0V 参考点。

### XTAL1、XTAL2

时钟相关引脚。

可以把时钟理解成单片机运行程序时使用的“节拍器”。

### RST

Reset，复位。

可以理解成让单片机重新从程序开头开始执行。

---

## 4. 二进制和十六进制

单片机底层最基本的两种状态：

- `0`：低电平
- `1`：高电平

因此经常使用二进制。

但二进制太长，所以程序中经常用十六进制表示。

### 4 位二进制对应 1 位十六进制

```text
0000 = 0
0001 = 1
0010 = 2
...
1001 = 9
1010 = A
1011 = B
1100 = C
1101 = D
1110 = E
1111 = F
```

因此：

```text
1111 = F
```

所以：

```text
1111 1111 = FF
```

C 语言里十六进制前面加 `0x`：

```c
0xFF
```

所以：

```text
0xFF = 十六进制 FF = 二进制 11111111
```

注意：

```text
0x
```

只是告诉 C 语言：

**后面的数字按十六进制解释。**

---

## 5. 为什么 `P0 = 0xFF` 能控制 8 个引脚

P0 是一组 8 位 I/O 口：

```text
P0.7 P0.6 P0.5 P0.4 P0.3 P0.2 P0.1 P0.0
```

而：

```text
0xFF = 11111111
```

所以：

```c
P0 = 0xFF;
```

等价于让 P0 的 8 个引脚全部为 1。

对应关系：

```text
二进制：  1    1    1    1    1    1    1    1
引脚：   P0.7 P0.6 P0.5 P0.4 P0.3 P0.2 P0.1 P0.0
```

注意：

**最右边那一位对应 P0.0。**

例如：

```text
0xFE = 11111110
```

所以：

```text
P0.0 = 0
其他 P0 引脚 = 1
```

# 6. 这块板子的 LED 为什么是 0 亮、1 灭

按照 PPT，这块板子的 LED 是：

**低电平有效。**

因此：

```text
0 → LED 亮
1 → LED 灭
```

原因可以先简单理解成：

LED 的另一端接向电源，当控制端被拉成低电平时，可以形成电流通路，所以 LED 点亮。

因此以后不要死记：

```text
1 = 开
0 = 关
```

要看具体电路。

在本实验板 LED 电路中：

```text
0 = 亮
1 = 灭
```

---

# 7. 74HC573 是什么

74HC573 是一个：

**锁存器**

目前只需要认识三类引脚：

- `1D ~ 8D`：数据输入端
- `1Q ~ 8Q`：数据输出端
- `LE`：锁存允许端

可以先理解成：

```text
D = 数据进去
Q = 数据出来
LE = 决定是否让数据传过去 / 锁住
```

### 当 LE = 1

Q 跟着 D 变化。

例如：

```text
1D = 0
↓
1Q = 0
```

### 当 LE = 0

Q 保持之前的数据。

即使 D 后来变化，Q 仍然保持原来的状态。

这就是“锁存”的含义：

**把刚才的数据记住。**

# 8. P0 和 LED 的关系

在这块实验板上，可以先理解为：

```text
P0
 ↓
74HC573
 ↓
LED
```

例如第一个 LED 的控制思路：

```text
P0.0
 ↓
74HC573 输入
 ↓
74HC573 对应输出
 ↓
第一个 LED
```

但 P0 的数据不是任何时候都能直接通过 74HC573。

还需要控制 74HC573 的：

```text
LE
```

而这个 LE 由 `Y4C` 控制。

---

# 9. 74HC138 是什么

74HC138 可以先理解成：

**用 3 个输入，从 8 路输出中选择一路。**

它的三个输入：

```text
A0
A1
A2
```

在本实验板中：

```text
P2.5 → A0
P2.6 → A1
P2.7 → A2
```

因此：

```text
P2.7 P2.6 P2.5
```

组成一个 3 位二进制数。

因为 3 位二进制有：

```text
2³ = 8
```

种组合，所以可以选择：

```text
Y0 ~ Y7
```

---

# 10. 为什么要设置 `P2.7 P2.6 P2.5 = 100`

LED 这一组对应 `Y4`。

十进制 4 的二进制是：

```text
100
```

因此需要：

```text
P2.7 P2.6 P2.5 = 1 0 0
```

也就是：

```text
A2 A1 A0 = 1 0 0
```

74HC138 因此选中：

```text
Y4
```

---

# 11. 为什么选中 Y4 后，Y4 = 0

74HC138 的输出是：

**低电平有效。**

意思是：

**哪一路被选中，哪一路就输出 0。**

所以：

```text
选择 Y4
↓
Y4 = 0
```

可以记：

```text
74HC138：选中谁，谁就是 0
```

---

# 12. 74HC02 和 Y4C

Y4 接下来进入 74HC02。

74HC02 是：

**或非门**

在 PPT 这部分电路中，另一个输入固定接地，也就是 0。

所以当：

```text
Y4 = 0
```

另一个输入也是：

```text
0
```

先做“或”：

```text
0 或 0 = 0
```

再取反：

```text
0 → 1
```

所以：

```text
Y4C = 1
```

---

# 13. Y4C 怎么控制 74HC573

`Y4C` 接到 74HC573 的 `LE`。

所以：

```text
Y4C = 1
↓
LE = 1
↓
74HC573 允许 P0 的数据传到 Q 输出端
```

这时 P0 才能真正决定 LED 的状态。

---

# 14. LED 完整控制逻辑

这是本次实验最重要的一条链。

## 第一部分：P2 负责“把 LED 这一组打开”

```text
P2.7 P2.6 P2.5 = 100
        ↓
74HC138 选择 Y4
        ↓
Y4 = 0
        ↓
经过 74HC02
        ↓
Y4C = 1
        ↓
74HC573 的 LE = 1
        ↓
74HC573 允许 P0 数据通过
```

## 第二部分：P0 决定“具体哪盏灯亮”

例如：

```text
P0.0 = 0
    ↓
数据进入 74HC573
    ↓
对应 Q 输出 = 0
    ↓
第一个 LED 亮
```

因此可以把整个实验逻辑总结为：

**P2.5、P2.6、P2.7 负责选择 / 打开 LED 这一组。**

**P0 负责决定这一组 LED 的具体亮灭状态。**

---

# 15. 最核心的一句话

```text
P2 → 负责“选 LED”
P0 → 负责“LED 怎么亮”
```

完整链路：

```text
P2.5 / P2.6 / P2.7
        ↓
     74HC138
        ↓
       Y4
        ↓
     74HC02
        ↓
      Y4C
        ↓
74HC573 的 LE
        ↓
允许 P0 数据通过
        ↓
      LED
```

# 16. 开始看 C 代码

## `sbit` 是什么

例如：

```c
sbit HC138_A = P2^5;
```

意思不是立即控制 P2.5。

它只是：

**给 P2.5 这个引脚起一个名字 `HC138_A`。**

所以：

```c
HC138_A = 0;
```

就相当于：

```c
P2.5 = 0;
```

同理：

```c
sbit HC138_B = P2^6;
sbit HC138_C = P2^7;
```

就是：

```text
HC138_B 代表 P2.6
HC138_C 代表 P2.7
```

---

# 17. `main()` 是什么

程序一般有：

```c
void main()
{
    ...
}
```

可以先理解为：

**`main()` 是程序开始执行的地方。**

单片机上电运行程序后，会执行 `main()` 中的代码。

例如：

```c
HC138_C = 1;
HC138_B = 0;
HC138_A = 0;
```

因为：

```text
HC138_C = P2.7
HC138_B = P2.6
HC138_A = P2.5
```

所以等价于：

```text
P2.7 P2.6 P2.5 = 100
```

作用：

**让 74HC138 选中 Y4，从而打开 LED 这条控制通路。**

---

# 18. `led1 = 0;` 是什么意思

如果程序前面写：

```c
sbit led1 = P0^0;
```

就是：

**给 P0.0 起名字叫 `led1`。**

所以：

```c
led1 = 0;
```

等价于：

```c
P0.0 = 0;
```

然后：

```text
P0.0 = 0
↓
74HC573
↓
对应输出 = 0
↓
第一个 LED 亮
```

因此在这块板子上：

```c
led1 = 0;   // 第一个 LED 亮
led1 = 1;   // 第一个 LED 灭
```

---

# 19. `while(1);` 是什么

例如：

```c
while(1);
```

可以先理解为：

**一直停在这里。**

因为：

```text
while = 当条件成立时一直循环
1 = 永远成立
```

所以：

```c
while(1);
```

就是一个永远不会结束的循环。

在“点亮第一个 LED”的程序中：

```c
led1 = 0;
while(1);
```

含义就是：

```text
先把第一个 LED 点亮
↓
然后程序一直待在这里
```

LED 就保持当前状态。
