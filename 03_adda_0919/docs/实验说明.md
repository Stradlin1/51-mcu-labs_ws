# 按键与 ADC 实验说明

## 共同硬件依据

接线以你上传的《实验四. 按键原理 ADDA》以及《实验三. 数码管 定时器和中断》为准。

| 控制对象 | 接线／选择值 | 程序处理 |
|---|---|---|
| LED 锁存器 | Y4，P2 高三位为 `0x80` | LED 低电平点亮 |
| 蜂鸣器、继电器锁存器 | Y5，`0xA0` | 初始化写 `0x00`，关闭输出 |
| 数码管位选锁存器 | Y6，`0xC0` | `0x01` 为第 1 位，依次到 `0x80` |
| 数码管段选锁存器 | Y7，`0xE0` | 共阳段码，`0xFF` 熄灭，`0xBF` 为短横线 |
| 独立按键 | P3.0、P3.1、P3.2、P3.3 | 按下读到 0 |
| 矩阵键盘行，从上到下 | P3.0、P3.1、P3.2、P3.3 | 逐行拉低扫描 |
| 矩阵键盘列，从左到右 | P4.4、P4.2、P3.5、P3.4 | 注意并非连续的 P3 高四位 |
| PCF8591 时钟 | P2.0，SCL | 软件 I²C |
| PCF8591 数据 | P2.1，SDA | 软件 I²C |
| 电位器 | PCF8591 AIN3 | 8 位结果 0～255 |

旧 LED 笔记中有关 Y5 可能连接数码管的说法属于当时未确认的推断；本次采用后续课件明确给出的 Y5／Y6／Y7 对应关系。

初始化会关闭蜂鸣器、继电器、LED 和数码管。写完锁存器后，清除 P2 高三位并将 P0 清零。动态显示每次先关闭位选，再更新段码，最后点亮目标位，减少重影。

所有工程使用定时器 1 的 1 ms 节拍，12 MHz、12T，初值 `0xFC18`。模式 0 在实际 IAP15F2K61S2 上是 16 位自动重装；与传统 AT89C52 的模式 0 含义不同。因此 Keil 的 AT89C52 模拟器不能准确模拟本板定时器及 P4、ADC 外设。

## 01_ws：独立按键控制 LED

跳帽 J6 接 **2–3**。

| 按下的键 | 引脚 | 点亮的 LED |
|---|---|---|
| KEY2 | P3.0 | LED1 |
| KEY6 | P3.1 | LED2 |
| KEY10 | P3.2 | LED3 |
| KEY14 | P3.3 | LED4 |

按下连续稳定约 20 ms 后点亮，松开后在下一次按键采样时熄灭。允许同时按住多个独立按键，相应的 LED 同时亮。LED5～LED8 熄灭，数码管不显示。

**预期现象参考，尚未上板实测：**上电后 LED 全灭，按住 KEY2 时 LED1 点亮，松开后熄灭；KEY6、KEY10、KEY14 分别控制 LED2、LED3、LED4，操作规律相同。

## 02_ws：00～59 可控计数

跳帽 J6 接 **2–3**。题目 key1～key4 按四个独立按键处理，实际使用左侧的 KEY2、KEY6、KEY10、KEY14。

| 实际按键 | 操作 |
|---|---|
| KEY2 | 加 1；59 后回到 00 |
| KEY6 | 减 1；00 后回到 59 |
| KEY10 | 立即归零 |
| KEY14 | 在自动加 1与暂停之间切换 |

前两位上电显示 `00`，后六位熄灭。稳定按下一次只触发一次，长按不会连续加减。松开稳定约 20 ms 后才能再次触发；同时按多个键不执行操作，应全部松开后再单键操作。

自动运行时每秒加 1，59 后回到 00；暂停时保持原数。按归零键只清零数值，不改变当前自动／暂停状态。每次有效操作都会重置当前 1 秒间隔；重新启动后等完整 1 秒再加 1。题目没有指定端点处理，本包采用 00～59 循环。

**预期现象参考，尚未上板实测：**上电显示 00，按加键变为 01，按减键回到 00，继续按减键变为 59；按归零键显示 00。按启停键后每秒增加 1，再次按下停止变化，显示当前数值。

## 03_ws：前四位静态显示 0～F

跳帽 J6 接 **1–2**。按键按物理位置从左到右、从上到下编号 1～16，映射字符 0～F。

上电显示 `0000`。按第 1 个矩阵键保持 `0000`，按第 2 个显示 `1111`，依此类推，按第 16 个显示 `FFFF`；松开后保持最后一次显示，后四位熄灭。

这道题没有轮流扫描四位数码管；一次性开启前四个位选，四位共享同一个段码，属于课件中的静态显示。定时器只用于按键消抖。

数码管的 B、D 常写成 `b`、`d` 字形，以区别 8、0；这与课件段码一致。

**预期现象参考，尚未上板实测：**依次按下 16 个矩阵键，前四位依次显示 0000、1111、2222，直至 FFFF，松手保持对应字符。

## 05_ws：电位器 ADC

缓慢调整板上的电压调节电位器。前五位保持短横线，后三位显示带前导零的三位十进制 ADC 结果，例如 `-----000`、`-----007`、`-----128`、`-----255`，约每 200 ms 更新一次。旋转增减方向由电位器接线决定。

程序使用外部 PCF8591，不是单片机内部 ADC。A0～A2 接地，7 位地址为 `0x48`，总线上发送的写、读地址字节分别是 `0x90`、`0x91`。

课件前部“滑变接 AIN1”与后面示例矛盾；本包以第 24 页示例的电位器 AIN3 为准。控制字使用 `0x03`，选择 AIN3 单端输入并关闭自动递增和 DAC 输出；课件中的 `0x43` 同样选择 AIN3，但额外打开了 DAC。本题只要求 ADC，因此保持 DAC 关闭。

每次读取先丢弃首个旧转换结果，随后读取本次结果。正常情况下显示数字；尚未成功读取或收到非应答时显示 `--------`，下一次采样会重试。

**预期现象参考，尚未上板实测：**电位器改变时，数码管前五位保持短横线，后三位在 000～255 范围内随电位器变化。端点能否精确达到 000、255，应以上板测量为准。

## 遇到问题先检查

1. 按键无效：确认烧录的是本题 HEX，01／02 的 J6 为 2–3，03／04 为 1–2。
2. 第 2 题按错键：使用左侧一列 KEY2、KEY6、KEY10、KEY14，对应加、减、归零、启停。
3. 自动计数偏快或偏慢：核对 STC-ISP 实际系统时钟为 12.000 MHz。Keil 的 Xtal 值本身不会设置芯片时钟。
4. ADC 一直显示八个横线：检查 PCF8591 的供电，以及 P2.0／SCL、P2.1／SDA 是否被其他外接模块占用。
5. 刚烧录时状态异常：彻底断电后重新上电，再观察。程序采用本次课件的完整锁存器初始化。
