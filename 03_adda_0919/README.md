# 03_adda_0919

五道按键、矩阵键盘和 ADC 实验，每题一个独立 Keil C51 工程。

## 直接使用

1. 先完整解压 `03_adda_0919.zip`，不要在压缩包里直接打开工程。
2. 打开对应子目录中的同名 `.uvproj`，例如 `01_ws/01_ws.uvproj`。
3. 在 Keil 中点击 Rebuild（重新编译）。工程已经勾选 Create HEX File。
4. 编译成功后，烧录该题 `Objects` 目录里的同名 `.hex`，例如 `01_ws/Objects/01_ws.hex`。
5. STC-ISP 的芯片型号选择实际实验板的 **IAP15F2K61S2**，本包程序所用系统时钟为 **12.000 MHz**。烧录完成后断电，等待 2～3 秒，再上电观察。

Keil 工程目标沿用仓库的 **Atmel → AT89C52**，这是编译配置；程序按实际 **IAP15F2K61S2** 的外设编写。已配好工程和启动文件，无需重新建立工程或添加启动文件。

**时间要准确，STC-ISP 中的实际系统时钟必须设为 12.000 MHz。仅修改 Keil 的 Xtal 设置不会改变芯片运行频率。** 本次采用 ADDA 课件的 12 MHz 配置，未沿用旧工程模板里的 24 MHz 设置。

## 五个工程

| 子文件夹 | 打开的工程文件 | 实现功能 | J6 跳帽 |
|---|---|---|---|
| `01_ws` | `01_ws.uvproj` | 四个独立按键按住亮灯，松开熄灭 | 2–3 |
| `02_ws` | `02_ws.uvproj` | 前两位显示 00～59；加、减、归零、自动计时启停 | 2–3 |
| `03_ws` | `03_ws.uvproj` | 矩阵键映射 0～F，前四位静态显示同一字符 | 1–2 |
| `04_ws` | `04_ws.uvproj` | 16 个矩阵键显示 1～16 的平方 | 1–2 |
| `05_ws` | `05_ws.uvproj` | 电位器 ADC，显示 `-----000`～`-----255` | 本题不用按键 |

## 先看这两个对应关系

**第 2 题**的文字把四个独立按键称作 key1～key4，而课件原理图将左侧四个按键标为 KEY2、KEY6、KEY10、KEY14。本包按独立按键题的上下文，将它们依次对应为：

| 题目名称 | 板上／课件按键标号 | 功能 |
|---|---|---|
| key1 | KEY2 | 加 1 |
| key2 | KEY6 | 减 1 |
| key3 | KEY10 | 归零 |
| key4 | KEY14 | 自动加 1／暂停 |

**第 3 题**按课件对“静态显示”的定义实现：前四位同时显示同一个字符，例如 `0000`、`1111`、`AAAA`、`FFFF`。不是四位分别显示 `0123`。数码管共享段线，四位显示不同字符需要动态扫描。
